# [Crypto Sandbox](https://crypto-sandbox.vercel.app) - A Mock Crypto Trader

This project was focuses on learning backend skills, particularly websockets and API's. 

## Tech Stack

### Backend 
- TypeScript
- Node w/ Express
- Socket.io
- API Secured w/ JWT Authentication

### Frontend
- TypeScript
- React w/ Vite

### Other Tools
- Docker for Development
- Deployed w/ Vercel @ [https://crypto-sandbox.vercel.app](https://crypto-sandbox.vercel.app)

## Structure

/client -> houses all frontend

/server -> houses all backend

## AI Usage

Because this was primarily a backend project, AI Generated code is used more frequently on the client/frontend.
